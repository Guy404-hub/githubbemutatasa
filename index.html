A GitHub bemutatása

A GitHub egy weboldal, ahol a programkódod és bármilyen projekted előzményekkel együtt tárolható, és többen dolgozhattok rajta egyszerre. Alább kipróbálhatod, hogyan működik a lényege.

Próbáld ki: így épül fel egy projekt története

Minden kör egy commit, vagyis egy elmentett állapot. A vonalak az ágak (branch-ek).

Gyűjtsd be mind a négy jelvényt! Billentyűk: C commit, B ág, S váltás, M merge.

Mi az a GitHub?

A GitHub egy felhős szolgáltatás Git-tárolókhoz. Fejlesztők, diákok, cégek és nyílt forráskódú közösségek használják kód, dokumentáció vagy akár egy weboldal közös kezelésére.

Három fő okból népszerű: nem vész el semmi (minden változás visszakövethető), többen dolgozhattok ugyanazon, és a munkafolyamatok nagy része automatizálható.

Funkciók: mi mire jó?

Kattints egy funkcióra, vagy válaszd ki, mi a helyzeted, és megmutatjuk, melyik segít.

Git és GitHub: mi a különbség?

Git

Ingyenes program a saját gépeden. A változásokat követi, internet nélkül is működik.

  • Verziókezelő eszköz
  • Parancssorból használod
  • Magát a „mentési előzményt” kezeli

GitHub

Webes szolgáltatás, amely Git-tárolókat tárol az interneten, és ráépít együttműködési eszközöket.

  • Online tárhely a projektnek
  • Pull requestek, issue-k, automatizálás
  • Közösség: mások kódját is láthatod és javíthatod
